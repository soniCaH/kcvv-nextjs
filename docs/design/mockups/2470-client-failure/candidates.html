What the three contexts expose

  • A's real cost is context 2. <Alert> is a document with a kicker, a title and a drop shadow. Announcing a failed pagination click, it outweighs the content that survived — and because it has no action slot, the retry becomes a second object beside it.
  • B removes an object rather than adding one. On /zoeken the empty and failed states stop being two different things in the same slot. Nothing new is invented: Tier 1, Tier 2 and the accent are all already decided.
  • B makes the tier carry the meaning. Tier 1 = your whole surface is gone. Tier 2 = one slot is gone, the page is intact. That is the same distinction #2427 already draws for emptiness, so a visitor learns it once.
  • The one thing B must decide (Q6): #2427's Tier 2 carries no action. Context 2 needs one, because the control it replaced is hidden. Context 3 does not, because the submit button survives. That suggests the rule is not “Tier 2 has no action” but “the failure adds an action only when the control it replaced is gone” — which is measurable per site, not a matter of taste.
  • Either way <Alert> ends up with zero consumers if B wins, since /zoeken is its only one. That is a deletion to decide on deliberately, not a side effect.
