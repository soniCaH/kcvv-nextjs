Is there a job for a fluoro ink?

Riso's punch comes from one fluorescent ink used once per sheet. §4.3 proposes a --color-fluoro rationed harder than green — at most once per page, on the genuinely urgent thing.

The problem is not the colour. It is that the three jobs C1 names are already taken or already forbidden.

C1's three use cases, checked against the code

  1. "Cancelled match" — occupied. MatchStatusBadge already ships it: cancelled → bg-card-red text-cream, abbreviation CANC. The loud tier exists and has a colour.
  2. "Live score" — forbidden. PRODUCT.md:56 lists live in-play scores among the things this site "does not have, and must not be designed as if it did".
  3. "An alert stamp" — card-red again. Same colour, same weight, same slot.

So a fluoro cannot simply be added. It either replaces card-red, or it needs a job that card-red genuinely does not do — and there is exactly one candidate for that, shown as option C below.

A fluoro badge cannot keep cream type

Cream on #ff3300 lands at 3.3 : 1, below the shipped badge's 4.4 : 1, and it is thin mono caps at 10px. Ink on fluoro reads at 5.4 : 1 — better than what ships today. But that flip changes what the badge is: cream-on-red is a stamp; ink-on fluoro is a highlighter. Both are in our vocabulary, and they are not the same gesture.

The one thing card-red genuinely cannot say. A per-match badge cannot express "the whole weekend is off" — that is club-wide, it outranks every row, and it is the real thing a parent checks the site for on a wet Saturday morning. Fluoro as a band, never as a badge, appearing perhaps six times a season.

Two constraints on whatever wins. The per-match badge lives on the fixture row, so anything touching it is gated on #2599 — that row's geometry is still unsettled and a status marker's position moves with it. And option C is not purely a design choice: a club-wide cancellation band needs a source of truth. The six-state machine in api-contract is per match, so "all off" is either derived (every match this weekend is cancelled or postponed) or authored in Sanity. Derived is honest and free; authored is faster to publish and can carry a reason. That is a separate question, and it only gets asked if C wins.
