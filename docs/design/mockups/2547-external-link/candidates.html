What marks a link that leaves the site

Two rules are already locked. This page only asks what the mark is, in the two places the rules leave it.

Rule 1. The mark rides the sentence, not the control. A card, tile or button whose visible content is the destination gets nothing.

Rule 2. A verb-labelled control gets the mark only when the act itself happens off-site — when the visitor is handed to a third party.

Where the mark now lands

Every target="_blank" link in scope, classified by the two locked rules. Six get a mark, eight do not. Five of the six are controls, so whatever is chosen has to work in mono caps on a warm fill as well as inline at 17px.

A — in prose

Real production copy from /nieuws/2024-03-25-kopzorgen-het-voetbal and /nieuws/2025-06-20-definitieve-reeksindeling-3e-nationale-bis. Note the shape editors actually write: four of the six external body links on the site have a bare URL as their link text. The highlighter marker is a hover reveal (background-size: 0% at rest), so at rest the mark is the only cue there is. Hover a link to see the marker arrive under it.

A1ArrowSquareOutwhat ships today

De volledige reportage van Pano is te bekijken via VRT MAX: https://www.vrt.be/vrtmax/a-z/pano/2024/pano-s2024a5/

De reeksindeling werd bevestigd in de communicatie van Voetbal Vlaanderen van 20 juni.

For: already shipping, unambiguous, a box-with-arrow is the web's most literate "new window" idiom. Against: it is a box at 0.75em beside 17px letterforms — at reading size it reads as a smudge, and on the bare-URL case it arrives at the end of a 52-character string nobody finished reading.

A2ArrowUpRightsame family as →

De volledige reportage van Pano is te bekijken via VRT MAX: https://www.vrt.be/vrtmax/a-z/pano/2024/pano-s2024a5/

De reeksindeling werd bevestigd in de communicatie van Voetbal Vlaanderen van 20 juni.

For: one stroke, so it survives 0.8em; it is → rotated, which makes the site's two arrows read as one vocabulary — along vs away — and that is a distinction a reader can learn once. It is also the Phosphor component version of the ↗ already hand-typed in six places, so it retires the character without changing what anyone sees there. Against: a bare diagonal is one rotation away from the glyph that means "stay", which is either the whole point or the whole problem.

A3The host, no glyphrule 1's own logic

De volledige reportage van Pano is te bekijken via VRT MAXvrt.be

De reeksindeling werd bevestigd in de communicatie van Voetbal Vlaanderenvoetbalvlaanderen.be van 20 juni.

For: this is rule 1 applied to prose rather than abandoned at the paragraph edge — a sponsor tile needs no mark because the logo names the destination, and here the host does the same job. It says where, not merely away, and it is the only candidate that improves the bare-URL case instead of decorating it: the 52-character URL collapses to vrt.be. Against: it is a content transform, not a mark — it changes what the link says, and an editor who wrote the full URL on purpose loses it. It also puts a mono run inside body copy, which is a type decision #2417 owns.

For: the arrow says away, the host says where; nothing is left to infer. Against: two marks for one fact, and in a paragraph with three links it is a lot of furniture. Also the widest — on a 320px measure it forces more wraps than any other candidate.
