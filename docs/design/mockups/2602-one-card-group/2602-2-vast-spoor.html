Vast spoor — wat het de telefoon kost.

Vervolg op 2602-1. Variant C maakt de kaart groter door het minimum van het spoor op te trekken. Dat is precies wat het kolomaantal bepaalt — en boven 171px valt de telefoon van twee kolommen naar één. Links de telefoon (390px), rechts het bureaublad (1280px, geschaald). Zelfde data, zelfde kaart.

huidige staat

Twee kolommen op de telefoon, zeven op het bureaublad. De kaart meet overal 150–216px.

C

repeat(auto-fill, 200px) — zoals gerenderd

breekt de telefoon

De kaart staat vast op 200px en pakt links aan. Op het bureaublad blijft er een vaste strook van 152px rechts liggen — bij elke groep, op elke pagina — terwijl de kopregel wél tot 1216px doorloopt. Op de telefoon: één kolom van 200px in 358px, met 158px naast de kaart. De kaart wordt daar niet groter, alleen eenzamer.

C2

minmax(200px, 1fr)

breekt de telefoon

Geen reststrook: vijf sporen van 230px vullen de rij exact. Dat is de nette versie van C — en op het bureaublad de mooiste van de vier. Maar hetzelfde minimum werkt door naar beneden: één polaroid van 358px per rij, zestien rijen, ruim drie keer zoveel scrollen.

de enige C die niets breekt

minmax(150px,1fr) onder md, minmax(200px,1fr) erboven. De telefoon blijft exact zoals vandaag; het bureaublad krijgt de vijf grote kaarten waar C voor bedoeld is. Kost één breekpunt — de enige plek in de component waar er een staat.
