How a number renders

Every surface below is the real component markup on the real Typekit faces, with the real tokens. The bar at the bottom rewrites the decision live — so you are judging the change on the page, not a swatch. Hold Alt / ⌥ to label every figure with the role it has been assigned.

Four measured facts drive this page: the site defaults to oldstyle figures everywhere except two nodes on /club/ultras; tabular-nums does nothing on any face this site uses; lining-nums is the only working switch, and on Freight Sans it also equalises the widths; and font-mono currently resolves to the visitor's OS monospace font, not IBM Plex Mono.

Q2

tabular-nums is inert — delete it, keep it, or replace it

22 source sites carry tabular-nums. The kit has no tnum feature, so on all four families the class changes nothing. Here is the only surface where the alignment it promises actually matters — the standings table, whose points column is font-display-big.

Body face + tabular-nums. The class is inert, so the columns are proportional oldstyle and the digits do not line up.

B · lining-nums on the body face

Delete tabular-nums, add lining-nums. On Freight Sans this gives exactly equal widths — measured 100.0px for all ten digits. The points column stays display-big and still cannot align.

C · the column goes mono recommended

Mono is monospaced by construction, so every column aligns including the points — and it is the register DESIGN.md already assigns to a stat value.

The table cannot have both: there is no tabular figure set in either display face at any setting, so a display-big points column is a permanently ragged column. C is the only candidate where the number under Ptn lines up with the number above it.

Q5 · a shipped defect, not a candidate

“Mono” is not IBM Plex Mono anywhere on the site

--font-family-mono is declared in @theme, but Tailwind v4's key is --font-mono — so the generated font-mono utility is Tailwind's default stack, and the project's own .font-mono sits in @layer base and loses. 85 elements on /kalender alone, including the entire global nav. Flip Q5 in the bar and every mono glyph on this page changes.

What ships — the visitor's OS mono
WEDSTRIJDEN · 2 – 1 · 20:00

SF Mono on macOS · Consolas on Windows · Liberation Mono on Linux. The label register is a different typeface per visitor.

What DESIGN.md says — IBM Plex Mono
WEDSTRIJDEN · 2 – 1 · 20:00

Loaded on every page via next/font, and never applied by the utility that is supposed to reach it.
