Torn, deckled, or just trimmed?

The zigzag was scissors, not tearing — one amplitude, one period, teeth you can count. Paper does not fail regularly. Three alternatives below, all with lower amplitude and no countable teeth.

Second fix applied to B, C and D: the mask now tiles at a fixed 600px instead of stretching to the element, so the tooth size is identical on a phone and on a desktop. Panel A still stretches, which is the other half of why it read badly.

Still true regardless of which wins

The band needs bottom padding it does not have today — every panel here carries an extra ~24px so the edge eats paper rather than the last line of type. That is a real layout change, not a decoration.

StripedSeam already says "this section is taped to the page". A torn edge is a second answer to the same question. They can coexist only if they take different jobs — e.g. seam for a section that continues, tear for a section that ends. Otherwise one of the two wins.

Effectively straight, with three or four 3px nicks across 600px. The claim it makes is "this was cut by a machine that has cut a lot of paper" — the smallest possible version of the idea, and the easiest to defend as not-decoration.

All four are one CSS rule plus padding. The differences that matter are amplitude and whether the irregularity is authored (B, D — a path someone drew, which means someone has to draw it well) or generated (C — noise, which is never twice the same and never needs redrawing). If none of these clears the bar, T7 closes and section boundaries stay ruled.
