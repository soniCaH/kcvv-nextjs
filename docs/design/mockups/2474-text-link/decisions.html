Underline on hover, as today. A citation is where an answer came from, not somewhere you are being sent — it stays quiet and lets the answer above it lead. Three markers lighting up in one small row is a lot of green for a footnote.

Word lid van KCVV

  • Praktische informatie

Same marker as body copy. Mono is mixed case here, so it has descenders — the g in “Ploegen” — and the band binds the way it does in a sentence. This is the “one gesture everywhere” you were after, extended as far as the letterforms allow.

Either answer closes the ticket. Nothing else depends on it: the other eight decisions stand whichever you pick, and if you choose A and later decide the marker suits them, the rule already permits it — it is a one-line change, not a re-decision.
