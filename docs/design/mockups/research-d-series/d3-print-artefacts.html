Which print artefacts survive?

Three leftovers from §4.1 after D1 killed misregistration and ink bleed. They are unrelated to each other — one is the page ground, one is a single decorative image, one is a section edge — so this is one question with three independent answers rather than three questions.

Every one is opt-in and local. None is a token change, so none forces a site-wide re-baseline the way D2 would have.

T3 — the paperReal stock, or just the missing half of the noise?

§4.1 proposes replacing the procedural grain with a scanned JPEG tile. Before buying a 20 KB asset, here is what is actually missing. --pattern-paper-grain runs baseFrequency 0.9 — that is speckle only, uniform at every point. Real stock reads as paper because of low-frequency mottle: slow blotches across a hand's width. The right panel adds exactly that, still procedurally.

The ground alone

Same technique we already ship, one extra layer. No asset, no request, no weight budget, no fallback to maintain — and it is the axis a scanned tile was being bought for.

The honest version of T3

A scanned tile would still beat this on fibre detail, and it is the only way to get true paper structure. But it costs an asset, a repeat seam to hide, a weight budget, and a fallback path — and the perceptual gap it closes is mostly the low-frequency one, which costs nothing. If mottle is wanted, take it procedurally; if it is not wanted, T3 closes entirely.

The band needs bottom padding it did not need before, or the tear eats the last line. And the mask stretches with the viewport, so the tear's tooth size is not constant — narrow phone, fine teeth; wide desktop, coarse.

What T7 actually collides with

`StripedSeam` already owns "this section is taped to the page". A torn edge is a second answer to the same question, on the same surface. Per the project's own rule — one treatment per purpose, not one treatment for everything — these two want different jobs, or one of them wins.

Full-bleed masks also seam badly at fractional device pixel ratios, which is where the existing full-bleed rule came from. This is buildable; it is just not the free ornament it looks like.

Nothing here is coupled. Any combination of the three is coherent, including none of them. T3 is a two-line change to one CSS custom property; T5 is a filter plus a crest variant used in maybe two places; T7 is the only one that touches layout, because a torn edge needs padding to survive.
