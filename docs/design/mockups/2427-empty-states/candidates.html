#2427 · cross-page consistency walk

What a surface shows when it has nothing to show.

The five written rules are settled. What is not settled is what the two tiers look like — today 20 in-scope sites carry 12 treatments across three font families and both alignments. Pick one register per tier.

Settled in this session

  1. Two tiers. A whole-surface empty is a designed moment. An empty slot inside a populated page is quiet furniture.
  2. “Nog geen” only when it can still arrive. Otherwise “Geen”. So lineups stay Geen opstelling beschikbaar; sponsors and galleries are Nog geen ….
  3. Query surfaces name the act, everything else names the thing. /zoeken and HubSearch keep “treffers”/“resultaten”; gevonden is banned elsewhere, so /nieuws loses it.
  4. A filter that empties a surface must offer the undo. Genuine emptiness offers a way out only when an honest one exists.
  5. The copy is the tell. A filter-empty always names the active facet back to the reader; genuine emptiness never names a facet.
